# EthicStay

Marketing website for EthicStay holiday-stay properties in Kerala.

**Live site:** https://ethicstay.com *(pending domain setup — served via GitHub Pages)*

## Properties

- **Blessings Home** — 7BHK duplex villa, Puthuchira, Changanassery (Kottayam dist.)
  Full-villa stays, floor-wise bookings (Ground Floor / Upper Castle), and
  marriage-function hosting with front-yard pandal space.

## Structure

```
index.html          one-page site (Blessings Home)
assets/img/         web-compressed photos (max 1600px, q78)
assets/video/       property tour video
```

## Workflow

1. Edit locally, preview by opening `index.html` in a browser
2. Commit and push to `main`
3. GitHub Pages deploys automatically (~1 minute)

No staging, no build step, no server-side code.
